# Laberinto del Instituto de Haria: La Apuesta del As

**Laberinto del Instituto de Haria** es un juego de aventura y supervivencia en el que los jugadores deben explorar un misterioso instituto que en realidad es un **laberinto encantado**. Usando **cartas de as** como herramienta para orientarse y avanzar, el jugador debe escapar antes de que se acabe el **tiempo limitado**. ¡El laberinto cambia constantemente y cada decisión cuenta!

## Historia

Al atravesar una puerta aparentemente normal del **Instituto de Haria**, el jugador es transportado a un laberinto infinito lleno de **peligros**, **acertijos** y **trampas**. Para orientarse, el jugador cuenta con **cartas de as** dispersas a lo largo del laberinto, pero las cartas son limitadas. El objetivo es escapar antes de que el tiempo se agote, usando las cartas de manera estratégica.

## Características

### 1. **Movilidad**

El personaje principal tiene libertad para moverse por el laberinto, pero el entorno cambia constantemente. Los pasillos y las habitaciones pueden transformarse, lo que hace que la exploración sea desafiante. El jugador debe adaptarse rápidamente a los cambios para avanzar.

### 2. **Cartas de As**

Las **cartas de as** son claves para orientar al jugador. Existen varias cartas, cada una con poderes especiales:
- **Carta de As Roja**: Revela un camino secreto durante un corto periodo de tiempo.
- **Carta de As Negra**: Proporciona pistas sobre acertijos o trampas cercanas.
- **Carta de As Dorada**: Permite cambiar de sección en el laberinto o encontrar objetos clave.

Las cartas son limitadas, por lo que deben usarse con inteligencia para evitar quedarse sin recursos en momentos cruciales.

### 3. **Tiempo Limitado**

El jugador tiene un **tiempo limitado** para escapar del laberinto. A medida que avanza, el reloj sigue corriendo, y las cartas de as aceleran el paso del tiempo. Si el tiempo se acaba antes de escapar, el juego se pierde.

### 4. **Interacción**

Dentro del laberinto, el jugador puede interactuar con:
- **Personajes misteriosos**: Algunos ofrecen cartas de as o pistas a cambio de resolver acertijos o completar tareas.
- **Objetos mágicos**: Fragmentos de cartas, piedras mágicas que detienen el tiempo, o objetos que abren nuevas rutas.

### 5. **Desafíos y Peligros**

El laberinto está lleno de **trampas** (pozos, criaturas, paredes móviles) que el jugador debe evitar o resolver para no perder tiempo o vida. Algunas trampas desactivan las cartas de as, lo que hace que la gestión de recursos sea aún más difícil.

### 6. **Mapeado Dinámico**

El laberinto cambia a medida que el jugador avanza. Algunas áreas son fijas, pero otras se reorganizan constantemente. No hay un mapa fijo, por lo que la **memoria y la observación** son clave para avanzar. El jugador debe recordar las rutas y los puntos de referencia dados por las cartas de as.

## Objetivo

El objetivo del juego es **escapar del laberinto** antes de que se agote el tiempo. Usando las cartas de as de manera estratégica, el jugador debe navegar a través de las secciones cambiantes del instituto y superar las trampas y desafíos hasta llegar a la salida.
